# API Mahasiswa Sederhana (Acara 15-16)

1. Laragon: Start All.
2. Import `database/si_akademik_api.sql` (phpMyAdmin atau `mysql -u root < database/si_akademik_api.sql`).
3. Acara 15: `http://localhost/setoran-web/acara_15/si-akademik/api/mahasiswa.php`
4. Acara 16: `http://localhost/setoran-web/acara_16/si-akademik/api/mahasiswa` (URL bersih lewat `api/.htaccess`)
5. Uji dengan Postman (acara 16: import folder `postman/`).
